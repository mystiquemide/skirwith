# Demo And Evidence Plan

Target duration: under three minutes.

## Sequence

1. Show the confirmed GitHub receipt first.
2. Show trusted `.github/mergepay.yml` with redacted wallet addresses.
3. Show the approved merged PR and passing checks.
4. Show policy approval and canonical payment key.
5. Show KeeperHub simulation.
6. Show KeeperHub execution ID and terminal status.
7. Open the explorer-confirmed transaction.
8. Show receipt fields: chain, token, amount, recipient, execution ID, hash, link, policy result, audit reference.
9. Replay the event and show duplicate resolution with no new transaction.
10. Show an over-limit/invalid payout blocked before broadcast with `broadcastMade: false`.

## Recording Rules

- Use authentic live evidence only for final proof.
- Keep chain, token, amount, payment key, execution ID, and transaction hash visible.
- Mask API keys and private data.
- Keep backup successful transaction evidence.
- Narrate what the viewer can independently verify.
